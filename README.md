# Food Delivery System

## Introduction

The Food Delivery System is a software application that allows customers to browse restaurants, view food items, add food to a cart, place orders, make payments, and track their deliveries.

## Main Modules

1. User Registration and Login
2. Restaurant Management
3. Food/Menu Management
4. Food Search
5. Shopping Cart
6. Order Management
7. Payment
8. Delivery Tracking
9. Order History
10. Testing and Debugging

## Objective

The objective of this project is to develop a system that makes ordering food from restaurants convenient and efficient for customers.
